# ROI-EA Application Modernization M6 - Azure and Google Cloud Adapters

M6 adds Microsoft Azure and Google Cloud provider evidence alongside the existing AWS adapter.

Azure support is grounded in Azure Migrate application/cross-workload assessments, application and inventory CSV exports, dependency CSV exports, and downloadable assessment reports.

Google Cloud support is grounded in Migration Center asset inventory exports, performance exports, network dependency CSV reports, detailed pricing/TCO exports, offline assessment reports, and migration planning/recommendations.

M6 deliberately does not claim a universal provider export schema. CSV imports are classified by the user-selected documented report/export type, and raw rows remain provider evidence unless explicitly mapped.

AWS, Azure, and Google Cloud recommendations can coexist in the same canonical modernization workspace. No provider is automatically ranked or selected.
