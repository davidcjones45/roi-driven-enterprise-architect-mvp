# ROI-EA Application Modernization M5 — Portfolio Readiness & Delivery Capacity

M5 combines the accepted M1–M4 evidence into a portfolio-level decision-support view.

It does not use a universal modernization score and does not create an automatic schedule.

Application states:
- READY_TO_PLAN
- BLOCKED
- DEFERRED_FOR_EVIDENCE
- NO_VIABLE_ALTERNATIVE
- NOT_ASSESSED

The plan also shows candidate wave membership, sequencing layer when available, economics evidence, delivery capacity, and explicit skill shortfalls.

Capacity is represented as available FTE minus reserved FTE, compared with recorded demand. This is an intentionally simple capacity model for portfolio constraint visibility, not a resource-management or scheduling optimizer.

M5 does not authorize funding, migration, staffing, or release.
