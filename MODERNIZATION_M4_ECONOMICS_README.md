# ROI-EA Application Modernization M4 — Economics Integration

M4 adds evidence-aware modernization economics while keeping the model provider-neutral.

It separates current annual run cost, one-time transition cost, target annual run cost, explicitly quantified recurring benefits, and annual risk adjustments. It calculates run-cost avoidance, risk-adjusted annual benefit, simple payback, horizon ROI, discounted NPV, and transparent downside/base/upside stress cases.

Forecasts are not realized results. Qualitative benefits such as resilience, security, developer productivity, release velocity, or avoided outages remain unquantified unless a user enters a traceable amount or explicit modeled assumption.

The Economics tab supports a synthetic acceptance fixture, seeding M1 transition/run-cost estimates as labeled assumptions, configurable horizon and discount rate, and evidence-readiness checks.

M4 does not call cloud pricing APIs, select a provider, authorize spending, or create a finance-approved business case.
