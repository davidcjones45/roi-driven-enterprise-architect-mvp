# ROI-EA Application Modernization M8 - Outcome Measurement & Institutional Learning

M8 closes the modernization evidence loop by recording actual delivery outcomes against the forecast snapshot that informed the decision.

It records:

- planned versus actual duration;
- planned versus actual engineering effort;
- forecast versus actual transition cost;
- forecast versus actual annual run cost;
- expected versus observed annual benefit;
- cutover outcome;
- rollback occurrence;
- incident count;
- downtime;
- dependency surprises;
- architecture deviations;
- lessons learned;
- evidence provenance.

M8 also aggregates historical outcomes by provider and strategy to expose descriptive delivery evidence such as average variance and forecast error.

Important boundary:

Historical performance does not automatically select a future provider, architecture, or modernization strategy. Confidence-versus-error data is descriptive evidence, not a probabilistic calibration claim unless a statistically appropriate model is later added.
